# 補全輪廓待檢查案例

已查看全部 49 組獨立氣泡預覽，人工挑出尖角、V 形凹口、折返及不平順輪廓。
這是待檢查集合，不代表每個凹口都已證實是新算法造成；有些可能來自原輪廓、
尾部或分割後保留的缺口。對稱誤差低，不等於輪廓自然或中心正確。

- `01_visual_notches/`：20 組人工挑出的可疑輪廓，包含輕微案例。使用者截圖對應 `12-09_items_3_4/`。
- `02_hold/`：4 組含程式已拒絕補全的案例，共 6 個 hold 氣泡。
- 每組包含整頁趨勢圖、整頁中心圖、獨立形狀圖、局部放大圖，以及 `review.json` 中的原因。
- `review_manifest.json`：整體清單，保留原計算數值及人工判斷說明。

所有圖片均為複製或另存裁切；原本完整輸出、原圖及正式排版資料均未移動或修改。
本次僅整理案例，未修改補全演算法，原預覽中的綠點也沒有重新判為合格。
